# Roadmap

## 0.1 — Lightweight file workspace

- [x] Byte-preserving file classification and explicit save model
- [x] One-folder workspaces, loose-file windows, tree, tabs, and two-pane split
- [x] TextKit 2 editor with in-file find/replace
- [x] Curated Tree-sitter syntax highlighting
- [x] GFM Markdown reader
- [x] PDFKit and system previews
- [x] Read-only decoded-text and hex binary inspectors
- [x] Sandbox, security-scoped bookmarks, and `public.text` Finder registration
- [x] Synthetic fixture validation
- [x] Supplied-folder classification and local-link acceptance
- [x] Accessibility behavior, hostile-file, and large-file/long-line validation
- [x] Signed, notarized, and stapled release validation

Release gate completed: tests and license checks passed, and CI published the
Developer ID signed, Apple-notarized, stapled
[`v0.1.0` prerelease](https://github.com/dburkhardt/OpenPane/releases/tag/v0.1.0).

## Later, only when real use demands it

- Project-wide search and previewed Replace in Files
- More grammars or large-file editing
- Multi-root workspaces
- Formatter or language-server integration
- Quick Look extension

Git, terminal, debugging, arbitrary extensions, PDF editing, binary editing,
publishing, and proofreading are not current product goals.
